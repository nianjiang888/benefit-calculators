# 免责声明

## 本工具的性质

本测算器依据公开法条与司法解释做**算术推算**，输出的是**区间参考值**，不是法律意见，也不代表任何具体案件的裁判结果。

实际抚养费数额由父母双方协议确定；协议不成的，由人民法院根据子女实际需要、父母双方负担能力和当地实际生活水平三项因素综合判定。法官享有自由裁量权，个案结果可能与本工具测算结果存在显著差异。

## 使用限制

1. 本工具不构成律师-委托人关系，不替代专业法律咨询
2. 测算结果不得作为诉讼请求的唯一依据
3. 法条可能修订，本工具依据条款以标注版本为准，使用前请核对现行有效版本
4. 地方司法实践存在差异，本工具只做通用测算，不含地方细则

## 建议的核实渠道

- **法条原文**：最高人民法院官网、中国裁判文书网
- **当地人均消费支出**：当地统计局年度统计公报（区分城镇 / 农村常住居民）
- **同行业平均工资**：国家统计局分行业城镇单位就业人员平均工资
- **个案咨询**：当地法律援助中心（12348 公共法律服务热线）、执业律师
