# 抚养费测算公式库

本文列出引擎用到的每一个公式、取值来源，以及哪些是法条明文、哪些是实务惯例。

---

## 一、收入基数折算

### 1.1 有固定收入

```
月收入基数 = 支付方月总收入
```

**月总收入的口径**：工资、奖金、津贴、补贴等全部收入。

**必须提示用户的分歧**：有的法院按**应发**工资计算，有的按**实发**（扣完社保个税到手）计算。同一个人在两种口径下算出的抚养费可以差出两三百元，这是实务里最常见也最难统一的争议点。

依据：《婚姻家庭编解释（一）》第 49 条第 2 款

### 1.2 无固定收入（按年总收入）

```
月收入基数 = 当年总收入 ÷ 12
```

依据：第 49 条第 3 款 ——「无固定收入的，抚养费的数额可以依据当年总收入或者同行业平均收入，参照上述比例确定」

**局限提示**：收入波动大的行业（销售提成、自由职业、季节性经营）单看一年容易失真，建议取近三年平均。

### 1.3 无固定收入（参照同行业平均）

```
月收入基数 = 同行业平均月收入
```

依据：同上。

**局限提示**：同行业平均需要注明来源（统计部门分行业工资、招聘平台公开数据），不同来源差异可能很大。

## 二、比例区间

法条明文只有一档：

| 需负担子女数 | 比例区间 | 性质 |
|---|---|---|
| 1 名 | 20% ~ 30% | **法条明文**（第 49 条第 2 款） |
| 2 名 | 30% ~ 40% | 实务惯例（法条仅规定「可适当提高，一般不超 50%」） |
| 3 名 | 40% ~ 50% | 实务惯例（同上） |
| 4 名及以上 | 45% ~ 50% | 实务惯例，已贴近法定天花板 |

基准值取区间中值：1 名 25%、2 名 35%、3 名 45%、4 名及以上 47.5%。

第 49 条原文：

> 抚养费的数额，可以根据子女的实际需要、父母双方的负担能力和当地的实际生活水平确定。
> 有固定收入的，抚养费一般可以按其月总收入的百分之二十至三十的比例给付。负担两个以上子女抚养费的，比例可以适当提高，但一般不得超过月总收入的百分之五十。
> 无固定收入的，抚养费的数额可以依据当年总收入或者同行业平均收入，参照上述比例确定。
> 有特殊情况的，可以适当提高或者降低上述比例。

**关键提醒**：法条里是「一般可以」，不是「应当」。这意味着 20%~30% 是起点，不是终点——法院会结合子女实际需要、父母负担能力和当地生活水平三个因素调整。任何把这个区间当公式硬套的算法都是错的，本引擎给区间正是为了体现这一点。

## 三、月抚养费

```
月抚养费（低值） = 月收入基数 × 区间下限
月抚养费（基准） = 月收入基数 × 区间中值
月抚养费（高值） = 月收入基数 × 区间上限
```

---

## 四、给付期限与剩余月数

```
剩余月数 = (18 − 子女当前年龄) × 12
```

依据：第 53 条第 1 款 ——「抚养费的给付期限，一般至子女十八周岁为止」

**两类例外**：

1. **16 周岁可停止**：16 周岁以上不满 18 周岁，以其劳动收入为主要生活来源，并能维持当地一般生活水平的，父母可以停止给付抚养费（第 53 条第 2 款）
2. **18 周岁后仍需给付**：子女属于「不能独立生活的成年子女」——尚在校接受高中及其以下学历教育，或者丧失、部分丧失劳动能力等非因主观原因而无法维持正常生活（第 41 条）

---

## 五、一次性给付

```
一次性给付总额 = 月抚养费 × 剩余月数
```

依据：第 50 条 ——「抚养费应当定期给付，有条件的可以一次性给付」

**为什么只能当上限看**：

- 「有条件」是前提，实务中法院支持一次性给付的比例并不高
- 即便支持，也常因资金的时间价值（一次性拿出未来十年的钱）有所折让
- 一次性给付后如果发生大额医疗、教育支出，再主张会很被动

本引擎按**不折让**计算，报告中明确标注这是上限参考。

## 六、充足性校验（本技能的核心增值项）

```
参照值 = 当地月人均消费支出 ÷ 2
比值   = 月抚养费（基准） ÷ 参照值
```

**为什么除以 2**：父母双方对子女都有抚养义务，粗略按各负担一半处理。这不是法律标准，是一个有实务意义的粗略参照。

| 比值 | 结论 | 对应法条 |
|---|---|---|
| < 0.8 | 明显偏低 | 第 58 条第（一）项：原定抚养费数额不足以维持当地实际生活水平 |
| 0.8 ~ 1.0 | 略低 | 参照第 58 条第（一）项，差距不大可协商 |
| ≥ 1.0 | 充足 | 无 |

第 58 条原文：

> 具有下列情形之一，子女要求有负担能力的父或者母增加抚养费的，人民法院应予支持：
> （一）原定抚养费数额不足以维持当地实际生活水平；
> （二）因子女患病、上学，实际需要已超过原定数额；
> （三）有其他正当理由应当增加。

**这一步的价值**：按比例算出来的数字在形式上完全合法，但可能实际不够花。校验把这层窗户纸捅破，直接告诉用户"这个数在法律上站得住，但在你当地可能不够，而'不够'本身就是法定的增加理由"。

## 七、抚养费的法定范围

第 42 条：「抚养费」包括子女**生活费、教育费、医疗费**等费用。

**实务中的分层处理**：

- 常规的教育费（公立学校）、医疗费（医保范围内）→ 已包含在按月给付的抚养费内
- 超出常规的大额支出（私立学校、择校费、长期治疗、康复训练）→ 实务中通常另行主张，由双方分担（各半居多），依据是第 58 条第（二）项

本引擎的月抚养费**不含**大额教育、医疗的另行分担部分，报告中单独说明。

## 八、其他相关条款

| 条款 | 内容 | 引擎中的体现 |
|---|---|---|
| 民法典第 1067 条第 1 款 | 父母不履行抚养义务的，未成年子女或不能独立生活的成年子女有要求给付抚养费的权利 | 请求权基础 |
| 民法典第 1085 条 | 离婚后子女由一方直接抚养的，另一方应负担部分或全部抚养费 | 主要法律依据 |
| 解释一第 41 条 | 「不能独立生活的成年子女」的认定 | 成年子女例外提示 |

| 解释一第 43 条 | 婚姻关系存续期间拒不履行抚养义务的，子女可请求支付 | 提示项 |
| 解释一第 49 条 | 比例区间 | 核心公式依据 |
| 解释一第 50 条 | 定期给付，有条件可一次性给付 | 一次性给付公式 |
| 解释一第 51 条 | 无经济收入或下落不明的，可用财物折抵 | 提示项 |
| 解释一第 52 条 | 可协议由一方负担全部，但能力明显不足的不予支持 | 提示项 |
| 解释一第 53 条 | 给付至 18 周岁；16 周岁例外 | 期限计算 |
| 解释一第 58 条 | 可请求增加的三种情形 | 充足性校验 |

## 九、明确不属于本引擎测算范围

1. 婚内（未离婚）主张抚养费——依据不同（第 43 条），需另案处理
2. 继子女的抚养义务——涉及第 54 条，情形复杂
3. 变更姓氏与抚养费的关联——第 59 条规定不得因子女变更姓氏拒付抚养费
4. 强制执行——第 61 条，属执行程序问题
