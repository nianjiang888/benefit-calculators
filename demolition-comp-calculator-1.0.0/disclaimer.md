# 免责声明

## 本工具的性质

本测算器依据公开法条做**方案对比与法定下限校验**，输出的是**参考性测算**，不是法律意见，也不代表任何具体征收项目的补偿结果。

真正的补偿数额取决于两个关键事实：一是具有相应资质的房地产价格评估机构按房屋征收评估办法评估确定的房屋价值；二是市、县级人民政府依法制定的征收补偿方案。二者都不在本工具的控制范围内。

## 使用限制

1. 本工具不构成律师-委托人关系，不替代专业法律咨询
2. 测算结果不得作为补偿谈判或诉讼的唯一依据
3. 法条可能修订，本工具依据条款以标注版本为准，使用前请核对现行有效版本
4. 地方标准差异极大，本工具按你输入的参数计算，不内置任何省、市、县的具体标准
5. 本工具不对评估时点、评估机构资质、未经登记建筑的认定结果作任何预判

## 建议的核实渠道

- **法条原文**：中国政府网、国务院令第 590 号、《土地管理法》（2019 年修正）
- **当地征收补偿方案**：作出房屋征收决定的市、县级人民政府公布的补偿方案（含搬迁费、临时安置费、停产停业损失的具体标准）
- **类似房地产市场价格**：征收决定公告之日周边同类房屋成交价或评估价
- **个案咨询**：当地法律援助中心（12348 公共法律服务热线）、执业律师、房屋征收部门公开咨询渠道
