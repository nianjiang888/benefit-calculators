# 测算样例

以下样例均为引擎真实输出（`scripts/calculator.py` 可复现）。

---

## 样例 1：货币补偿，征收方报价低于市场价

**输入**：合法面积 90 ㎡，类似房地产市场价格 18,000 元/㎡，征收方报价 15,000 元/㎡，搬迁费 3,000 元，临时安置费 2,000 元/月 × 24 月，补助奖励 50,000 元

```bash
python scripts/calculator.py --area 90 --market-price 18000 --offer-price 15000 \
    --moving-fee 3000 --temp-monthly 2000 --temp-months 24 --subsidy 50000
```

**输出要点**：

| 项目 | 金额 |
| --- | --- |
| 被征收房屋价值补偿（按市场价下限 18,000 元/㎡） | 1,620,000.00 元 |
| 搬迁费 | 3,000.00 元 |
| 临时安置费 | 48,000.00 元 |
| 补助和奖励 | 50,000.00 元 |
| 货币补偿合计 | 1,721,000.00 元 |

**第 19 条下限校验**：征收方报价 15,000 元/㎡ 低于类似房地产市场价格 18,000 元/㎡，差额 270,000 元（90 ㎡ × 3,000 元）属于可主张的缺口。

**这一档最典型的用法**：拿着"报价低于市场价"的缺口数去谈，而不是接受一个形式上合规但实质偏低的单价。

## 样例 2：货币补偿 + 产权调换对比，报价不低于市场价

**输入**：合法面积 120 ㎡，市场价 16,000 元/㎡，报价 16,500 元/㎡，搬迁费 4,000 元，临时安置费 2,500 元/月 × 30 月，补助奖励 80,000 元，产权调换房屋 15,000 元/㎡ × 130 ㎡

```bash
python scripts/calculator.py --area 120 --market-price 16000 --offer-price 16500 \
    --moving-fee 4000 --temp-monthly 2500 --temp-months 30 --subsidy 80000 \
    --swap-price 15000 --swap-area 130
```

**输出要点**：

| 项目 | 金额 |
| --- | --- |
| 被征收房屋价值（按报价 16,500 元/㎡） | 1,980,000.00 元 |
| 方案 A 货币补偿合计 | 2,139,000.00 元 |
| 方案 B 产权调换折算总权益 | 2,113,000.00 元 |
| 产权调换差价结清 | 应由征收方结清 30,000 元 |
| 方案对比差额 | −26,000.00 元（货币补偿更有利） |

**必须告知用户**：报价 16,500 元/㎡ 不低于市场价 16,000 元/㎡，符合第 19 条下限要求——但这只是下限，不是应得数额。方案对比"货币补偿更有利"只是数字口径，产权调换房屋若区位好、行情看涨，折算权益可能更高，两种方案性质不同，不能只看差额。

## 样例 3：经营性用房 + 未经登记建筑 + 产权调换

**输入**：合法面积 200 ㎡，未经登记建筑 30 ㎡，市场价 22,000 元/㎡，报价 20,000 元/㎡，搬迁费 6,000 元，临时安置费 3,000 元/月 × 36 月，停产停业月净利润 15,000 元 × 6 月，补助奖励 100,000 元，产权调换房屋 19,000 元/㎡ × 210 ㎡

```bash
python scripts/calculator.py --area 200 --illegal-area 30 --market-price 22000 --offer-price 20000 \
    --moving-fee 6000 --temp-monthly 3000 --temp-months 36 \
    --biz-profit 15000 --biz-months 6 --subsidy 100000 \
    --swap-price 19000 --swap-area 210
```

**输出要点**：

| 项目 | 金额 |
| --- | --- |
| 被征收房屋价值（按市场价下限 22,000 元/㎡） | 4,400,000.00 元 |
| 方案 A 货币补偿合计 | 4,704,000.00 元 |
| 方案 B 产权调换折算总权益 | 4,300,000.00 元 |
| 产权调换差价结清 | 应由征收方结清 410,000 元 |
| 方案对比差额 | −404,000.00 元（货币补偿更有利） |

**未经登记建筑提示（第 24 条）**：存在未经登记建筑 30 ㎡。依第 24 条第 2 款，市县级政府作出征收决定前应当组织调查、认定和处理——认定为合法建筑和未超过批准期限的临时建筑的应当给予补偿，认定为违法建筑和超过批准期限的临时建筑的不予补偿。本测算未将上述面积计入补偿，认定结果直接影响最终数额，务必核实。

**实务提醒**：停产停业损失补偿（15,000 元/月 × 6 月 = 90,000 元）需以营业执照、纳税记录、近三年利润等效益证明为前提，本引擎按你填的数值计算，实际能否全额认定取决于你能否举证。
