# 征收拆迁补偿公式库

本文列出引擎用到的每一个计算逻辑、取值来源，并明确标注**哪些地方根本不存在公式**。

---

## 一、必须先说清楚：没有"补偿计算公式"

这是整个测算器最重要的前提，必须如实告知用户。

《国有土地上房屋征收与补偿条例》第 19 条第 1 款只规定：

> 对被征收房屋价值的补偿，不得低于房屋征收决定公告之日被征收房屋类似房地产的市场价格。被征收房屋的价值，由具有相应资质的房地产价格评估机构按照房屋征收评估办法评估确定。

也就是说：

1. 第 19 条规定的是**法定下限**，不是补偿公式；
2. 被征收房屋的具体价值由**评估机构评估**确定，不存在全国统一的单价或算法；
3. 因此本引擎**不声称能算出"你该拿多少钱"**，它的核心价值是：
   - **法定下限校验**（报价有没有低于类似房地产市场价格）；
   - **货币补偿 vs 产权调换的两方案对比**。

---

## 二、法定下限校验（第 19 条）—— 唯一的"硬计算"

```
base_price = max(offer_price, market_price)
house_value = base_price × legal_area
```

若 `offer_price < market_price`，则：

```
缺口 = (market_price − offer_price) × legal_area
```

含义：征收方提出的单价低于类似房地产市场价格，依第 19 条第 1 款"不得低于"的要求，这部分差额属于你可以主张的缺口。

若只提供了 `offer_price` 或 `market_price` 中的一项，无法做下限校验，引擎会明确提示"建议补充另一项"。

---

## 三、方案 A：货币补偿（第 17、19、22、23 条）

```
house_value = base_price × legal_area
temp_total  = temp_monthly × temp_months
biz_total   = biz_profit × biz_months
plan_a_total = house_value + moving_fee + temp_total + biz_total + subsidy
```

各项说明：

| 项目 | 算式 | 依据 | 是否公式 |
| --- | --- | --- | --- |
| 被征收房屋价值补偿 | `base_price × legal_area` | 第 17 条第（一）项、第 19 条 | 是（按你填的单价） |
| 搬迁费 | 输入值 | 第 17 条第（二）项、第 22 条 | **否**，标准由各地规定 |
| 临时安置费 | `temp_monthly × temp_months` | 第 22 条 | 是（按你填的月标准与月数） |
| 停产停业损失补偿 | `biz_profit × biz_months` | 第 17 条第（三）项、第 23 条 | 是（按你填的效益与期限） |
| 补助和奖励 | 输入值 | 第 17 条第 2 款 | **否**，按市县级政府办法 |

## 四、方案 B：房屋产权调换（第 21、22 条）

```
swap_value = swap_price × swap_area
diff       = swap_value − house_value        # 正=被征收人补差，负=征收方结清
moving_b   = moving_fee × 2                  # 实务常见搬迁两次
net        = −diff + moving_b + temp_total + biz_total + subsidy
equity     = swap_value + moving_b + temp_total + biz_total + subsidy − max(diff, 0)
```

- `diff_text`：正值时"需由被征收人补交差价"，负值时"应由征收方向被征收人结清"，零时"无需结清差价"。
- `net`：实际可得现金净额（结清差价后落到手里的钱或要掏的钱）。
- `equity`：折算总权益 = 调换房屋价值 + 各项补偿 − 需补差价。用于和货币补偿到手现金做对比。

**关键提醒**：产权调换房屋的价值取决于其区位与市场行情，随行情波动。比较两个方案的"数字大小"没有意义——货币补偿是确定的现金，产权调换是未来才确定的实物权益，两者性质不同。

---

## 五、方案对比

```
d = equity − plan_a_total
verdict = "产权调换总权益更高" if d > 0 else ("货币补偿更高" if d < 0 else "两者相当")
```

报告中会明确提示：不可简单以数字大小论优劣。

## 六、哪些地方是法条明文、哪些是实务惯例

| 内容 | 性质 | 依据 |
| --- | --- | --- |
| 补偿不得低于类似房地产市场价格 | **法条明文** | 第 19 条第 1 款 |
| 补偿含房屋价值、搬迁、临时安置、停产停业 | **法条明文** | 第 17 条 |
| 可选择货币补偿或产权调换 | **法条明文** | 第 21 条第 1 款 |
| 产权调换应计算、结清差价 | **法条明文** | 第 21 条第 2 款 |
| 先补偿、后搬迁 | **法条明文** | 第 27 条第 1 款 |
| 搬迁费、临时安置费具体标准 | **授权省级政府制定** | 第 22 条 |
| 停产停业损失具体办法 | **授权省级政府制定** | 第 23 条 |
| 产权调换搬迁费按两次计 | **实务惯例**（以当地方案为准） | 第 22 条（无明文倍数） |

## 七、明确不属于本引擎测算范围

1. **集体土地的分项测算**：集体土地适用《土地管理法》第 48 条而非 590 号令，补偿结构与标准不同。本引擎对 `collective` 类型只做结构提示，未做分项金额测算。
2. **评估机构的选定程序**：包括协商选定、投票、随机选定等程序性事项，属行政程序，不在测算范围内。
3. **强制执行的执行程序**：达不成协议时的补偿决定、复议、诉讼、强制执行，属程序法范畴。
4. **未经登记建筑的认定结果**：第 24 条第 2 款授权市县级政府调查、认定和处理，本引擎无法预判认定结论，仅提示其影响。
