# 赡养费测算器

赡养费数额的参照估算工具。判断给付要件是否成立，给出两档参照口径下的估算区间与两种分摊方案。

## 凭什么比现有同类强

SkillHub 上赡养费方向**此前是空白**（扫描 36 个权益类关键词时命中 0 个）。市面上零星可见的都是
"赡养义务科普"类内容，没有一个给出可计算的口径。

本技能的差异化不在"算得多准"——因为**赡养费没有法定公式，谁都算不准**——而在于把这件事说清楚：

| 能力 | 科普型内容 | 本技能 |
|---|---|---|
| 讲清赡养义务的三个方面 | 有 | 有 |
| **判断给付要件是否成立（第1067条第2款）** | 含糊 | **明确校验，「缺乏劳动能力」与「生活困难」满足其一即可** |
| **给出可计算的数额口径** | 无 | **有，两档参照** |
| **人数均摊 vs 按能力加权两种方案** | 无 | **有** |
| **如实声明「没有法定公式」** | 无（大多暗示有标准） | **有，写在报告第一条** |
| 可下载打印的测算报告 | 无 | 有（HTML） |

## 三条不糊弄的原则

1. **没有公式就说没有**。报告第一条写明：赡养费不存在法定计算公式或法定比例，
   这与抚养费有 20%~30% 比例区间完全不同。不暗示"存在一个标准答案"。
2. **两档口径的现实差距讲透**。保底档（低保标准）与合理档（人均消费支出）多数地区相差 3 倍以上，
   且**法院实际判决通常更接近保底档**——这条现实必须让用户知道，而不是只给个好看的数。
3. **惯例与法条分开标**。0.5 折算系数、两档口径、均摊方法全部标注为"实务惯例，法条无明文"。

## 快速开始

```bash
# 两档参照 + 按能力加权
python scripts/calculator.py --local-cost 2400 --dibao 680 \
    --elder-income 1500 --medical 800 --children 3 \
    --child-incomes 8000,5000,3000 --labor-lost

# 农村老人、无收入、需长期护理
python scripts/calculator.py --dibao 550 --local-cost 1600 \
    --elder-income 0 --medical 1500 --children 2 \
    --child-incomes 6000,2000 --labor-lost --care-required

# 生成报告
python scripts/calculator.py --dibao 550 --local-cost 1600 --medical 1500 \
    --children 2 --child-incomes 6000,2000 --html report.html
```

## 依据条款

《民法典》第26条、第1067条第2款；《中华人民共和国老年人权益保障法》第14、15、19、20条。

条款原文均经国家法律法规数据库、地方法院官方发布渠道核对。
