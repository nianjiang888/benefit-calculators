# 免责声明

## 一、本技能是什么

本技能是**赡养费数额的参照估算工具**。它做的事是：

- 按第1067条第2款判断给付赡养费的请求权**是否可能成立**
- 在两档参照口径下，估算月赡养费的大致区间
- 给出人数均摊与按能力加权两种分摊方案

## 二、本技能不是什么

- **不是法律意见**，不构成任何形式的法律建议
- **不是判决预测**。赡养费**没有法定计算公式**，任何声称能算出"你应该给 X 元"的工具都是不严谨的
- **不代替律师、人民调解委员会、法院的专业判断**

## 三、最重要的一条

**赡养费不存在法定计算公式或法定比例。**

这与抚养费不同——抚养费有《婚姻家庭编解释（一）》第49条明确的 20%~30% 比例区间，赡养费什么都没有。
法律只规定**义务成不成立**（第1067条第2款），数额由人民法院综合当地生活水平、被赡养人实际需要、
赡养人经济能力等因素确定。

本技能输出的每一个数额，都是**参照口径下的估算**，不是法律标准。

## 四、两档口径的现实差距

- **保底档**（参照当地低保标准）：对应司法实践中较常见的判决水平
- **合理档**（参照当地人均消费支出）：对应更体面的生活水平

在多数地区，这两档相差 3 倍以上。**法院实际判决通常更接近保底档**。

把这两档都列出来，是为了让你看清区间的宽度，而不是暗示"合理档就是你该拿到的数"。

## 五、你应当核实的事项

- 当地最新的城乡低保标准与人均消费支出（分城镇/农村口径，须按老人实际居住地取数）
- 老人的劳动能力状况、全部收入来源
- 医疗护理支出的真实性与持续性（一次性大额与长期固定，法院处理不同）
- 各子女的真实收入与自身家庭负担
- 是否已形成赡养协议（《老年人权益保障法》第20条）
- 是否有子女自身属低保对象、无经济能力的特殊情形

## 六、赡养义务不只是钱

《老年人权益保障法》第14条：赡养义务包含**经济上供养、生活上照料和精神上慰藉**三方面。
金钱给付只是其中之一。第19条：不得以放弃继承权或者其他理由拒绝履行赡养义务。

老人经济上不困难的，金钱赡养费请求可能不被支持，但生活照料与精神慰藉义务**不因此免除**。

## 七、查证入口

- **国家法律法规数据库**：https://flk.npc.gov.cn （民法典、老年人权益保障法权威文本）
- **最高人民法院**：https://www.court.gov.cn （司法解释、指导案例）
- **中国裁判文书网**：https://wenshu.court.gov.cn （查询本地同类案件的判决水平）
- **民政部门**：当地城乡低保标准的官方发布渠道
