# 样例

以下 3 组样例均为**实际运行 `scripts/calculator.py` 的真实输出**，未做手工修饰。

---

## 样例 1：两档参照 + 按能力加权（老人有养老金）

**场景**：某地城镇低保标准 680 元/月、人均消费支出 2400 元/月。老人有养老金 1500 元/月，
每月医疗护理刚性支出 800 元，缺乏劳动能力。3 名子女月收入分别为 8000、5000、3000 元。

```bash
python scripts/calculator.py --local-cost 2400 --dibao 680 \
    --elder-income 1500 --medical 800 --children 3 \
    --child-incomes 8000,5000,3000 --labor-lost
```

**输出**

```
【一、月需求测算】
  保底档（低保 680.00 + 医疗护理 800.00）：1,480.00 元/月
  合理档（人均消费 2,400.00 + 医疗护理 800.00）：3,200.00 元/月
  老人自有月收入：1,500.00 元
  月缺口（保底档）：0.00 元
  月缺口（合理档）：1,700.00 元

【二、分摊结论】子女 3 人
子女               月收入        均摊(保底)        均摊(合理)           按能力加权(合理)
第1位         8,000.00          0.00        566.67              850.00
第2位         5,000.00          0.00        566.67              531.25
第3位         3,000.00          0.00        566.67              318.75
  合计（合理档按能力加权）：1,700.00 元/月

【三、法条门槛校验（第1067条第2款）】
  满足给付要件：已声明老人缺乏劳动能力，满足第1067条第2款的给付要件之一
  （「缺乏劳动能力」与「生活困难」满足其一即可）。另一要件是「成年子女不履行赡养义务」，
  需就该事实举证。注意：按保底档测算，老人自有收入已覆盖基本需求、不形成经济缺口，
  按合理档测算仍有缺口。要件既已满足，法院可能在两档之间酌定数额，也可能仅支持部分请求。
```

**解读**：这个案例很典型——老人养老金 1500 元已超过保底档需求 1480 元，所以保底档缺口为 0；
但按合理档（含医疗护理）仍有 1700 元缺口。因为"缺乏劳动能力"这一要件已满足，请求权成立，
只是数额可能在两档之间。按能力加权后，收入 8000 元的子女承担 850 元，收入 3000 元的承担 318.75 元。

## 样例 2：农村老人、无收入、需长期护理

**场景**：某地农村低保标准 550 元/月、人均消费支出 1600 元/月。老人无收入、缺乏劳动能力、
生活不能自理，每月护理支出 1500 元。2 名子女月收入分别为 6000、2000 元。

```bash
python scripts/calculator.py --dibao 550 --local-cost 1600 \
    --elder-income 0 --medical 1500 --children 2 \
    --child-incomes 6000,2000 --labor-lost --care-required
```

**输出**

```
  保底档（低保 550.00 + 医疗护理 1,500.00）：2,050.00 元/月
  合理档（人均消费 1,600.00 + 医疗护理 1,500.00）：3,100.00 元/月
  老人自有月收入：0.00 元
  月缺口（保底档）：2,050.00 元
  月缺口（合理档）：3,100.00 元

子女               月收入        均摊(保底)        均摊(合理)           按能力加权(合理)
第1位         6,000.00      1,025.00      1,550.00            2,325.00
第2位         2,000.00      1,025.00      1,550.00              775.00
  合计（合理档按能力加权）：3,100.00 元/月

  满足给付要件：已声明老人缺乏劳动能力，满足第1067条第2款的给付要件之一。
```

**解读**：两名子女收入均不低于当地人均消费支出 1600 元，故都不触发 0.5 折算，
权重按 6000:2000 = 3:1 分配，合理档下分别承担 2325 元与 775 元。
均摊方案则是每人 1550 元（合理档）。两种方案差距明显，正是需要家庭协商的地方。

已声明生活不能自理，报告会额外提示《老年人权益保障法》第15条的照料责任：
赡养人应当承担照料责任，不能亲自照料的可以按老年人意愿委托他人或养老机构照料。

## 样例 3：只填保底档，老人收入充裕

**场景**：某地城市低保标准 750 元/月（未填人均消费支出）。老人月收入 2200 元，无医疗支出，
未声明缺乏劳动能力或生活困难。2 名子女月收入分别为 9000、4500 元。

```bash
python scripts/calculator.py --dibao 750 --elder-income 2200 --children 2 \
    --child-incomes 9000,4500
```

**输出**

```
  保底档（低保 750.00 + 医疗护理 0.00）：750.00 元/月
  合理档（人均消费 0.00 + 医疗护理 0.00）：— 元/月
  老人自有月收入：2,200.00 元
  月缺口（保底档）：0.00 元

【三、法条门槛校验（第1067条第2款）】
  可能未达给付要件：按保底档测算，老人自有收入已能覆盖基本生活需求，未形成经济缺口，
  且未声明缺乏劳动能力。依第1067条第2款，给付赡养费请求权的成立要件之一是父母
  「缺乏劳动能力」或「生活困难」；若经济上并不困难，单纯要求给付金钱赡养费可能不被支持。
  但需强调：经济供养只是赡养义务的一部分，生活照料与精神慰藉义务不因此免除
  （《老年人权益保障法》第14条）。
```

**解读**：只填一档时，另一档显示"—"，不影响计算。老人月收入 2200 元远超低保标准 750 元，
且未声明缺乏劳动能力，两个要件都不满足，金钱赡养费请求很可能不被支持。

**注意**：这不代表子女没有义务。生活照料与精神慰藉义务仍然存在，只是不以金钱给付的形式体现。
