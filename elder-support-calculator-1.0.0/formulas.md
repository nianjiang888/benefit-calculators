# 赡养费测算公式库

本文件说明 `scripts/calculator.py` 中每个算式的来源、依据条款与局限。

**总原则：赡养费无法定公式。本文件中除了「门槛校验」部分有法条依据外，
所有数额算式都属于实务惯例，不是法律标准。**

---

## 一、先分清两件事：义务 vs 数额

| 问题 | 有无法条依据 | 本引擎怎么处理 |
|---|---|---|
| 要不要给（义务是否成立） | **有**。第1067条第2款给出成立要件 | 门槛校验，依法条判断 |
| 给多少（数额） | **无**。没有任何法定公式或比例 | 两档参照口径估算，全部标注为惯例 |

这是本技能与抚养费测算器最大的区别，也是必须反复强调的一点。

---

## 二、门槛校验（法条明文）

**依据**：《民法典》第1067条第2款——成年子女不履行赡养义务的，**缺乏劳动能力或者生活困难的**父母，
有要求成年子女给付赡养费的权利。

成立要件有两个，且需同时满足：

1. 成年子女不履行赡养义务
2. 父母**缺乏劳动能力**或**生活困难**（**二者满足其一即可**）

引擎的判断逻辑：

```
若 已声明 缺乏劳动能力 或 生活困难：
    → 满足给付要件（要件2已满足，要件1需另行举证）
    → 若同时保底档无缺口，提示：法院可能在两档之间酌定，或仅支持部分请求
否则若 保底档缺口 ≤ 0：
    → 可能未达给付要件（经济上不困难，且未声明缺乏劳动能力）
    → 同时提示：生活照料与精神慰藉义务不因此免除（老年法第14条）
否则：
    → 要件待举证（需补充劳动能力状况与收支情况）
```

**为什么把声明判断放在最前面**：要件是"或"关系，满足其一即成立。
即便老人自有收入能覆盖基本需求，只要"缺乏劳动能力"成立，请求权依然成立——
只是数额可能因此被压低。这是本引擎修过的一个真实逻辑错误。

**相关条款**：
- 《老年人权益保障法》第19条：不得以放弃继承权或者其他理由拒绝履行赡养义务
- 《老年人权益保障法》第14条：赡养义务包含经济上供养、生活上照料和精神慰藉三方面

## 三、两档参照口径（实务惯例）

### 3.1 保底档

```
保底档月需求 = 当地月最低生活保障标准 + 月均医疗护理支出
```

**为什么用低保标准**：司法实践中，法院判决的赡养费数额通常参照当地城乡居民最低生活保障标准。
公开判例中每月 300 元量级的判决较为常见，这个水平与低保标准接近。

**来源性质**：**实务惯例**，法条无明文。

### 3.2 合理档

```
合理档月需求 = 当地月人均消费支出 + 月均医疗护理支出
```

**为什么用人均消费支出**：对应"保障老年人基本生活水平不低于当地居民平均水平"的实质目标，
比低保标准体面得多。

**来源性质**：**实务惯例**，法条无明文。

### 3.3 缺口

```
月缺口 = max(0, 月需求 − 老人月自有收入)
```

老人有养老金、租金等收入的，应当先抵扣。这是常识，也为实务通行做法。

**局限**：不区分"自有收入能否实际支配"（如被他人代管、被挪用的情形）。

## 四、分摊方式

### 4.1 人数均摊

```
每人应付 = 月缺口 ÷ 子女人数
```

**来源性质**：**实务惯例**。部分法院直接按人数均摊，不考虑子女收入差异。

### 4.2 按能力加权（实务惯例）

```
有效收入_i = 收入_i                            若 收入_i ≥ 当地人均消费支出
有效收入_i = 收入_i × 0.5                      若 收入_i < 当地人均消费支出

权重_i = 有效收入_i ÷ Σ 有效收入_j
每人应付_i = 月缺口 × 权重_i
```

**为什么有 0.5 折算**：收入本身低于当地人均消费支出的子女，其自身生活已属紧张，
若按全额收入加权会使其负担过重。0.5 是折中处理。

**来源性质**：**实务惯例，法条无明文**。不同法院做法差异大，有些直接均摊，
有些对无收入子女予以免除。

**局限**：
- 未考虑各子女的家庭负担（配偶无业、子女上学、自身患病等）
- 未考虑子女已实际承担照料责任的情况（出力可以折抵部分出资）
- 0.5 这个具体数字没有判例统计支撑，属工程折中，报告中原样标注

## 五、医疗护理支出的处理

**依据**：《老年人权益保障法》第15条——赡养人应当使患病的老年人及时得到治疗和护理；
对经济困难的老年人，应当提供医疗费用。对生活不能自理的老年人，赡养人应当承担照料责任；
不能亲自照料的，可以按照老年人的意愿委托他人或者养老机构等照料。

**引擎处理**：把医疗护理支出计入月需求后参与分摊。

**局限**：实际诉讼中，大额医疗支出常单独列支、另行主张，不一定并入基础赡养费。
本引擎的做法是简化，报告"说明与局限"中已提示。

## 六、引擎不处理的内容

| 内容 | 原因 |
|---|---|
| 赡养协议的具体效力 | 《老年人权益保障法》第20条，需个案审查不得违反法律与老年人意愿 |
| 出力折抵出资 | 无量化标准，实践差异极大 |
| 孙子女外孙子女的代位赡养义务 | 《民法典》第1074条，有特定前提条件 |
| 赡养纠纷中的精神损害赔偿 | 属另一请求权 |
| 机构养老费用的分摊细则 | 地域政策差异大 |
