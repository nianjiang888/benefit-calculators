# 遗产继承分配测算器

法定继承份额的算式工具。把《民法典》继承编的定性规则翻译成可计算的权重，输出各继承人的份额区间与可打印报告。

## 凭什么比现有同类强

SkillHub 上遗产继承方向的现有技能，基本都是**咨询/指南型**（讲道理、列步骤、给建议），没有一个给你算出具体份额。这个包补的是"算钱"这一环：

| 能力 | 咨询指南型 | 本技能 |
|---|---|---|
| 讲清继承顺序与继承人范围 | 有 | 有 |
| **算出每个人的具体份额** | 无 | **有** |
| **夫妻共同财产先分一半（第1153条）的基数处理** | 口头提及 | **进入算式** |
| **债务清偿上限（第1161条）** | 口头提及 | **进入算式，资不抵债时净额归零** |
| **同一类别内不同情形的细分** | 无 | **有，支持 `support=1,neglect=1`** |
| **法条明文与惯例估算的区分标注** | 无 | **每条输出都标** |
| 可下载打印的测算报告 | 无 | 有（HTML） |

## 三条不糊弄的原则

1. **法条没给的数字，明确标成惯例**。第1130条只说"一般应当均等""可以"多分、"应当"不分或者少分，
   **没有任何比例数字**。报告里的调整幅度（1.1~1.3 倍、0.5~0.8 倍）在输出中原样标注为"实务惯例估算"。
2. **算不准的就说算不准**。必留份的「必要份额」由人民法院按实际情况确定，不存在可公式化的标准，
   引擎只做定性提示，不编造数额。
3. **份额是相对值这件事讲清楚**。全员适用同一系数时归一化后与均分一致，属于数学必然；
   区间按"他人固定、本人浮动"计算，避免同步浮动导致的低值大于高值。

## 快速开始

```bash
# 标准均分
python scripts/calculator.py --estate 1200000 --marital yes \
    --spouse 1 --children 2 --parents 2 --debts 100000

# 组内细分
python scripts/calculator.py --estate 800000 --children 2 \
    --children-spec "support=1,neglect=1"

# 生成报告
python scripts/calculator.py --estate 1200000 --marital yes \
    --spouse 1 --children 2 --parents 2 --html report.html
```

## 依据条款

《民法典》第1122、1123、1127、1128、1129、1130、1141、1152、1153、1154、1155、1159、1161条；
《最高人民法院关于适用〈中华人民共和国民法典〉继承编的解释（一）》（法释〔2020〕23号）第14条、第25条。

条款原文均经国家法律法规数据库、最高人民法院公报等官方渠道核对。
