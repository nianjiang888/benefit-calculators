# 免责声明

## 一、本技能是什么

本技能是一个**法定继承份额的算式工具**。它把《民法典》继承编的定性规则翻译成可计算的权重，
帮助你理解"大致会怎么分"，用于：

- 家庭内部协商前，先搞清楚各自的份额区间
- 与律师沟通前，预先整理事实与争议点
- 判断某个分配方案是否明显偏离法定口径

## 二、本技能不是什么

- **不是法律意见**，不构成任何形式的法律建议
- **不是判决预测**，人民法院的裁判会考虑本技能未建模的诸多因素
- **不代替律师、公证处、人民调解委员会的专业服务**

## 三、结果的性质

1. **份额是区间参考值**，不是精确值。第1130条只作定性规定，法条没有给任何比例数字。
2. **调整幅度是实务惯例估算**，不是法条标准。报告中的 1.1~1.3 倍、0.5~0.8 倍用于呈现不确定性，
   不代表法院必然采纳。
3. **「必要份额」的数额不可计算**。必留份只做定性提示。
4. **引擎不处理遗嘱、遗赠、遗赠扶养协议的具体分配**。有遗嘱的优先按遗嘱（第1123条）。

## 四、你应当核实的事项

- 遗产是否确为被继承人个人财产，有无夫妻财产约定或其他共有权人
- 债务的性质（个人债务 / 夫妻共同债务 / 担保债务）
- 各继承人是否存在「缺乏劳动能力又没有生活来源」的情形
- 是否存在代位继承（第1128条）、转继承（第1152条）、丧偶儿媳女婿继承（第1129条）
- 各类财产的评估口径、过户税费与当地政策
- 是否存在涉外因素（涉及冲突规范与准据法）

## 五、查证入口

本技能引用的条款，建议在以下官方渠道核对原文：

- **国家法律法规数据库**：https://flk.npc.gov.cn （全国人大，民法典、土地管理法等权威文本）
- **中国政府网**：https://www.gov.cn （行政法规，如国务院令第590号）
- **最高人民法院**：https://www.court.gov.cn （司法解释、指导案例、公报）
- **中国裁判文书网**：https://wenshu.court.gov.cn （同类案件的裁判尺度）
