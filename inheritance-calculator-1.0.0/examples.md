# 样例

以下 5 组样例均为**实际运行 `scripts/calculator.py` 的真实输出**，未做手工修饰。

---

## 样例 1：标准法定继承，夫妻共同财产

**场景**：被继承人遗留夫妻共有财产 120 万元，有配偶、2 名子女、2 位父母，被继承人尚有债务 10 万元。

```bash
python scripts/calculator.py --estate 1200000 --marital yes \
    --spouse 1 --children 2 --parents 2 --debts 100000
```

**输出**

```
遗产总额             1,200,000.00 元
配偶先分（第1153条）    600,000.00 元
计入遗产部分         600,000.00 元
减：债务清偿         100,000.00 元
可分配遗产净额       500,000.00 元

继承顺序：第一顺序（配偶、子女、父母）   合计 5 人（份）

继承人           人数情形                         基准份额        每人基准(元)                 每人区间(元)
配偶             1一般情形                     20.00%     100,000.00 100,000.00 ~ 100,000.00
子女             2一般情形                     40.00%     100,000.00 100,000.00 ~ 100,000.00
父母             2一般情形                     40.00%     100,000.00 100,000.00 ~ 100,000.00
```

**解读**：先按第1153条分出配偶一半 60 万，剩余 60 万为遗产；再按第1159条清偿债务 10 万，净额 50 万；5 名第一顺序继承人均分，每人 10 万。全部为一般情形，故区间等于基准值。

## 样例 2：组内细分（最常见的争议形态）

**场景**：个人财产 80 万元（非夫妻共有），配偶 1 人生活特殊困难又缺乏劳动能力，2 名子女中 1 人尽了主要扶养义务、1 人有扶养能力和条件但长期不尽义务。

```bash
python scripts/calculator.py --estate 800000 --marital no \
    --spouse 1 --spouse-kind care --children 2 --children-spec "support=1,neglect=1"
```

**输出**

```
可分配遗产净额       800,000.00 元

继承人           人数情形                         基准份额        每人基准(元)                 每人区间(元)
配偶             1生活特殊困难又缺乏劳动能力            40.00%     320,000.00 303,448.28 ~ 335,483.87
子女             1尽了主要扶养义务或与被继承人共同生活       40.00%     320,000.00 303,448.28 ~ 335,483.87
子女             1有扶养能力和条件但不尽扶养义务          20.00%     160,000.00 137,931.03 ~ 200,000.00
```

**解读**：权重 = 配偶 1.2、多分子女 1.2、少分子女 0.6，合计 3.0，故 40% / 40% / 20%。
区间按"他人固定、本人浮动"计算：少分子女的系数在 0.5~0.8 之间浮动时，其份额在 17.24%~25% 之间。

**注意**：配偶与多分子女的基准份额相同（都是 1.2），这不是疏漏——系数相同则相对比例相同，是权重法的必然结果。

## 样例 3：债务超过遗产

**场景**：个人财产 30 万元，无配偶子女父母，有兄弟姐妹 2 人、祖父母 1 人，债务 35 万元。

```bash
python scripts/calculator.py --estate 300000 --marital no --spouse 0 --children 0 --parents 0 \
    --siblings 2 --grandparents 1 --debts 350000 --must-keep
```

**输出**

```
减：债务清偿         350,000.00 元
  说明：债务 350,000.00 元不低于遗产 300,000.00 元，可分配遗产为 0。
       依据第1161条，继承人以所得遗产实际价值为限清偿，超过部分自愿偿还的除外；
       放弃继承的可不负清偿责任。
可分配遗产净额      0.00 元

继承顺序：第二顺序（兄弟姐妹、祖父母、外祖父母）   合计 3 人（份）

兄弟姐妹             2一般情形                     66.67%            0.00               0.00 ~ 0.00
祖父母、外祖父母         1一般情形                     33.33%            0.00               0.00 ~ 0.00
```

**解读**：第一顺序无人，第二顺序参与。债务吞没全部遗产，可分配净额为 0。
超过遗产实际价值的 5 万元，继承人自愿偿还的除外；放弃继承的可不负清偿责任（第1161条）。

## 样例 4：胎儿保留份

**场景**：夫妻共有财产 200 万元，有配偶、1 名子女、2 位父母，另有尚未出生的胎儿 1 名。

```bash
python scripts/calculator.py --estate 2000000 --marital yes \
    --spouse 1 --children 1 --fetus 1 --parents 2
```

**输出**

```
配偶先分（第1153条）  1,000,000.00 元
计入遗产部分        1,000,000.00 元
可分配遗产净额      1,000,000.00 元

继承顺序：第一顺序（配偶、子女、父母）   合计 5 人（份）

配偶             1一般情形                     20.00%     200,000.00 200,000.00 ~ 200,000.00
子女             1一般情形                     20.00%     200,000.00 200,000.00 ~ 200,000.00
父母             2一般情形                     40.00%     200,000.00 200,000.00 ~ 200,000.00
胎儿（保留份）        1一般情形                     20.00%     200,000.00 200,000.00 ~ 200,000.00
```

**解读**：胎儿按一个完整份额保留（第1155条）。胎儿娩出时是死体的，保留的份额按照法定继承办理；
出生后为活体的，保留份归其所有。

## 样例 5：必留份情形

**场景**：个人财产 90 万元，2 名子女，其中 1 人生活特殊困难又缺乏劳动能力，且符合「缺乏劳动能力又没有生活来源」。

```bash
python scripts/calculator.py --estate 900000 --marital no --children 2 \
    --children-spec "care=1" --must-keep
```

**输出**

```
可分配遗产净额       900,000.00 元

继承人           人数情形                         基准份额        每人基准(元)                 每人区间(元)
子女             1生活特殊困难又缺乏劳动能力            54.55%     490,909.09 471,428.57 ~ 508,695.65
子女             1一般情形                     45.45%     409,090.91 409,090.91 ~ 409,090.91
```

**必留份校验**

```
存在必留份继承人：遗嘱应当为缺乏劳动能力又没有生活来源的继承人保留必要的遗产份额（第1141条）。
遗嘱未保留的，遗产处理时应当先为该继承人留下必要遗产，剩余部分才可参照遗嘱分配
（《继承编解释（一）》第25条）。「必要份额」的具体数额由人民法院根据实际情况确定，
本测算不代替认定。
```

**解读**：权重 = 1.2 + 1.0 = 2.2，故 54.55% / 45.45%。
必留份的「必要份额」数额**不可公式化**，引擎只做定性提示。
