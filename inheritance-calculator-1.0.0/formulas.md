# 遗产继承分配测算公式库

本文件说明 `scripts/calculator.py` 中每一个算式的来源、依据条款与局限。
**原则是：法条明文与实务惯例分开标注，绝不把惯例包装成法条。**

---

## 一、可分配遗产基数

### 1.1 配偶先分（法条明文）

```
若 夫妻共同财产 且 有配偶：
    配偶先分额 = 遗产总额 × 1/2
    计入遗产部分 = 遗产总额 × 1/2
否则：
    配偶先分额 = 0
    计入遗产部分 = 遗产总额
```

**依据**：《民法典》第1153条第1款——「夫妻共同所有的财产，除有约定的外，遗产分割时，应当先将共同所有的财产的一半分出为配偶所有，其余的为被继承人的遗产。」

**局限**：
- 有书面财产分别所有制约定的，按约定处理，不适用本条
- 家庭共有财产中的遗产，应先分出他人的财产（第1153条第2款），本引擎未建模
- 若遗产中含被继承人婚前个人财产，应先行剔除后再适用本条

### 1.2 债务清偿（法条明文）

```
若 债务 ≥ 计入遗产部分：
    可分配净额 = 0   （提示第1161条：以遗产实际价值为限）
否则：
    可分配净额 = 计入遗产部分 - 债务
```

**依据**：
- 《民法典》第1159条——「分割遗产，应当清偿被继承人依法应当缴纳的税款和债务；但是，应当为缺乏劳动能力又没有生活来源的继承人保留必要的遗产。」
- 《民法典》第1161条第1款——「继承人以所得遗产实际价值为限清偿被继承人依法应当缴纳的税款和债务。超过遗产实际价值部分，继承人自愿偿还的不在此限。」

**局限**：引擎按债务总额全额扣除，未区分夫妻共同债务、担保债务、连带责任份额。

## 二、继承人范围与顺序（法条明文）

```
若 配偶 + 子女 + 父母 + 胎儿 > 0：
    适用第一顺序，第二顺序不参与
否则：
    适用第二顺序（兄弟姐妹、祖父母、外祖父母）
```

**依据**：《民法典》第1127条第1、2款。

**相关条款（引擎未自动建模，需用户自行计入人数）**：
- 第1128条 代位继承：被继承人的子女先于被继承人死亡的，由其直系晚辈血亲代位继承；兄弟姐妹先于被继承人死亡的，由其子女代位继承。代位继承人一般只能继承被代位人有权继承的份额
- 第1129条 丧偶儿媳/女婿尽了主要赡养义务的，作为第一顺序继承人
- 第1152条 转继承：继承开始后、遗产分割前继承人死亡且未放弃继承的，其应继份额转给其继承人
- 第1155条 胎儿保留份：引擎按用户输入 `--fetus` 计入一份

## 三、份额计算：权重法

### 3.1 为什么用权重法

第1130条对份额调整只作**定性**规定，没有任何数字。要把它变成可计算的东西，
只能引入权重，且必须让"一般应当均等"在默认情形下自然成立。

### 3.2 基准份额（法条明文 + 惯例幅度）

```
权重_i = 系数(情形_i) × 人数_i
份额_i = 权重_i / Σ 权重_j
每人份额_i = 份额_i / 人数_i
```

**系数表（法条只定性，幅度为实务惯例估算）**

| 情形 | 低 | 基准 | 高 | 法条依据 | 幅度性质 |
|---|---|---|---|---|---|
| `normal` 一般情形 | 1.0 | 1.0 | 1.0 | 第1130条第1款 | **法条明文**：一般应当均等 |
| `care` 生活特殊困难又缺乏劳动能力 | 1.1 | 1.2 | 1.3 | 第1130条第2款 | 定性为法条（应当予以照顾），**幅度为惯例估算** |
| `support` 尽了主要扶养义务或共同生活 | 1.1 | 1.2 | 1.3 | 第1130条第3款 | 定性为法条（可以多分），**幅度为惯例估算** |
| `neglect` 有能力有条件不尽扶养义务 | 0.5 | 0.6 | 0.8 | 第1130条第4款 | 定性为法条（应当不分或者少分），**幅度为惯例估算** |
| `exclude` 不分 | 0 | 0 | 0 | 第1130条第4款 | **法条明文**：应当不分 |

**重要提醒**：这张表里的 1.1/1.2/1.3、0.5/0.6/0.8 **不是法条规定的数字**。
法条只说"照顾""多分""少分"，没有量化。这些幅度用于呈现区间，不代表法院必然采纳。

### 3.3 一个反直觉但必须说清的数学事实

份额是**相对值**。若让所有继承人的系数同步上下浮动，归一化后相对比例会被抵消，
甚至出现"少分的人系数变大 → 其他人份额反而下降"的反转，呈现出来就是低值大于高值，无法阅读。

因此区间采用**个体假设**：

```
对于继承人 i：
    自身权重 = 系数_i[低 or 高] × 人数_i
    他人权重 = Σ (系数_j[基准] × 人数_j)   j ≠ i
    份额_i[低 or 高] = 自身权重 / (自身权重 + 他人权重)
```

语义是：**假设其他人的情形固定不变，仅本人的调整幅度在惯例区间内浮动时，本人可得金额的下限与上限。**

### 3.4 组内细分

同一类别内部不同继承人可适用不同情形，通过 `--<类别>-spec "情形=人数[,情形=人数]"` 指定，
未指定的人数归入该类别的整体情形（默认 `normal`）。

这是继承纠纷最常见的形态，例如"两个子女，一个长期照料老人、一个常年不露面"。

## 四、必留份（法条明文，数额不可计算）

**依据**：
- 《民法典》第1141条——「遗嘱应当为缺乏劳动能力又没有生活来源的继承人保留必要的遗产份额。」
- 《继承编解释（一）》第25条——「遗嘱人未保留缺乏劳动能力又没有生活来源的继承人的遗产份额，遗产处理时，应当为该继承人留下必要的遗产，所剩余的部分，才可参照遗嘱确定的分配原则处理。继承人是否缺乏劳动能力又没有生活来源，应按遗嘱生效时该继承人的具体情况确定。」

**引擎的处理**：只做定性提示，**不计算具体数额**。
「必要份额」的数额由人民法院按被继承人的遗产状况、继承人的实际需要、当地生活水平等综合确定，
不存在可公式化的标准。

## 五、引擎不处理的内容

| 内容 | 原因 |
|---|---|
| 遗嘱的具体分配 | 第1123条优先适用遗嘱，引擎算的是法定继承份额 |
| 遗赠、遗赠扶养协议 | 同上，优先于法定继承 |
| 遗产酌给制度 | 继承人以外依靠被继承人扶养的人可以分给适当遗产，无量化标准 |
| 各类财产的评估与税费 | 地域差异极大，需专业机构 |
| 涉外继承 | 涉及冲突规范与准据法 |
| 继承权丧失（第1125条） | 需司法认定，引擎按用户声明处理 |
